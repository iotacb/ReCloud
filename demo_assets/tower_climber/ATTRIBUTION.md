# Tower Climber asset credits

## Original sprites

`enemy-basic.png`, `enemy-flying.png`, `enemy-evader.png`, and
`xp-crystal.png` were generated specifically for this project with OpenAI image
generation and processed into transparent game sprites.

## Sound effects

The jump, XP, level-up, game-over, stomp, hurt, and UI sound files are selected
from Kenney's **Digital Audio**, **Impact Sounds**, **Sci-fi Sounds**, and
**UI Audio** packs. The cinematic level-up sound layers `forceField_004.ogg`
and `explosionCrunch_004.ogg` from **Sci-fi Sounds**.
